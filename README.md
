# Ai xlcex 📊

**Ai xlcex** is an intelligent, AI-assisted spreadsheet application designed to manipulate, calculate, and format tabular data through natural language instructions.

## 🚀 Architecture
- **Frontend:** React, Tailwind CSS, Vite, Lucide Icons
- **Backend:** FastAPI, Python, Pandas, OpenPyXL
- **LLM Engine:** Multi-modal spreadsheet reasoning API

## 🛠️ Quickstart

### 1. Backend Setup
```bash
cd server
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
cd client
npm install
npm run dev
